# Glossary

| Term | Plain-English meaning |
|---|---|
| Market Risk | Risk of loss caused by movements in market prices or risk factors. |
| VaR | Value at Risk; a modeled loss threshold at a chosen confidence level and horizon. |
| 99% 1-day VaR | A model threshold intended to be exceeded on roughly 1% of days if the model is well calibrated. |
| Expected Shortfall | Average loss in observations already worse than the VaR threshold. |
| Historical VaR | VaR estimated directly from the historical P&L distribution. |
| Parametric VaR | VaR estimated from an assumed distribution, here the normal distribution. |
| Monte Carlo VaR | VaR estimated from simulated outcomes. |
| Weighted Historical VaR | Historical VaR where recent observations receive more probability weight. |
| P&L | Profit and loss. |
| Risk factor | Market variable that changes the value of a position. |
| Position | An economic exposure to an instrument. |
| Long | Position that generally benefits when the instrument price rises. |
| Short | Position that generally benefits when the instrument price falls. |
| Volatility | Degree of variation in prices or P&L. |
| Correlation | Degree to which two variables move together. |
| Diversification | Risk reduction caused by imperfectly correlated positions. |
| Component VaR | Portion of total parametric VaR attributed to one position. |
| Stress test | P&L under a predefined market shock. |
| VaR exception | Realized loss worse than the prior VaR forecast. |
| Backtesting | Comparing model forecasts with realized outcomes. |
| Kupiec test | Test of whether the number of VaR exceptions is consistent with the expected exception rate. |
| Christoffersen test | Test of whether VaR exceptions appear independent rather than clustered. |
| Risk limit | Approved maximum level of a risk measure or exposure. |
| Limit utilization | Current risk divided by the approved limit. |
| Limit breach | Risk measure exceeds its approved limit. |
| Continuous futures series | Long price history created by linking futures contracts through time. |
| Model risk | Risk that a model is wrong, incomplete, misused, or inappropriate for current market conditions. |
